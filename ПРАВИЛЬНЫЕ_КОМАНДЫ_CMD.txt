  ПРАВИЛЬНЫЕ КОМАНДЫ ДЛЯ CMD (каждая команда отдельно!)
═══════════════════════════════════════════════════════════════

⚠️  ВАЖНО: Каждую команду нужно выполнять ОТДЕЛЬНО и нажимать Enter!


ШАГ 1: Перейти в папку проекта
───────────────────────────────────────────────────────────────
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS"

(Нажмите Enter)


ШАГ 2: Активировать виртуальное окружение
───────────────────────────────────────────────────────────────
venv\Scripts\activate.bat

(Нажмите Enter, должно появиться (venv) в начале строки)


ШАГ 3: Обновить pip
───────────────────────────────────────────────────────────────
python -m pip install --upgrade pip

(Нажмите Enter, дождитесь завершения)


ШАГ 4: Установить библиотеки (по одной!)
───────────────────────────────────────────────────────────────

Команда 1:
python -m pip install opencv-python==4.8.1.78

(Нажмите Enter, дождитесь завершения)


Команда 2:
python -m pip install easyocr==1.7.0

(Нажмите Enter, дождитесь завершения - это может занять 5-10 минут)
