ЗАПУСК:
-------
Двойной клик: ФИНАЛЬНЫЙ_ЗАПУСК.bat
Или: СТАРТ.bat


ЧТО ПРОИСХОДИТ:
---------------
1. Проверяется окружение (Python, Node.js)
2. Создается venv и устанавливаются зависимости
3. Запускается бэкенд (порт 8000)
4. Запускается фронтенд (порт 3000)
5. ПРОВЕРЯЕТСЯ готовность серверов (до 120 секунд!)
6. Браузеры открываются ТОЛЬКО когда серверы готовы
7. Если серверы не готовы - показывается предупреждение


КЛЮЧЕВЫЕ ОТЛИЧИЯ:
-----------------
✅ Проверка готовности ДО 120 секунд
✅ Показ статуса каждые 2 секунды
✅ Цветное оформление (зеленый=OK, желтый=ждем, красный=ошибка)
✅ Окна серверов помечены "НЕ ЗАКРЫВАЙТЕ!"
✅ Браузер открывается ТОЛЬКО после готовности
✅ Несколько попыток открытия браузера


ВАЖНО:
------
НЕ ЗАКРЫВАЙТЕ окна серверов во время работы!
Они должны оставаться открытыми.


ЕСЛИ НЕ РАБОТАЕТ:
