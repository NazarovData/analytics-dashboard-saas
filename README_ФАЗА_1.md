## 📊 КАК ИСПОЛЬЗОВАТЬ

### **Шаг 1: Подготовьте данные**

Создайте CSV или Excel файл с колонками:
```csv
date,product,quantity,price,client_id
2024-01-15,iPhone 15,2,80000,CLIENT001
2024-01-15,AirPods,1,15000,CLIENT001
2024-01-16,MacBook Pro,1,150000,CLIENT002
```

**Обязательные колонки:**
- `date` - дата заказа
- `product` - название товара
- `quantity` - количество
- `price` - цена за единицу
- `client_id` - ID клиента

### **Шаг 2: Загрузите файл**

1. Войдите в систему

3. Подождите 2-5 секунд

## 📞 ПОДДЕРЖКА

**Если что-то не работает:**

1. **Файл не загружается:**
   - Проверьте формат (CSV/Excel)
   - Проверьте наличие обязательных колонок
   - Проверьте консоль браузера (F12)

2. **Сервер не запускается:**
   - Убедитесь что виртуальное окружение активировано
   - Установите pandas: `pip install pandas openpyxl`
   - Проверьте что порт 8000 свободен

3. **Frontend пустой:**
   - Установите recharts: `npm install recharts`
   - Проверьте что backend работает
   - Очистите кэш браузера (Ctrl+Shift+R)
