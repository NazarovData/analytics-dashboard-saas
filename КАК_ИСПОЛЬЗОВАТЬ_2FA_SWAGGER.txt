🔐 КАК ИСПОЛЬЗОВАТЬ 2FA В SWAGGER
=================================

✅ ИСПРАВЛЕНО: Теперь user_id правильно передаётся!


📋 ПРОСТАЯ ИНСТРУКЦИЯ:
======================

1. ОТКРОЙТЕ SWAGGER:
   http://localhost:8000/docs

2. НАЙДИТЕ РАЗДЕЛ "2fa"

3. ВЫБЕРИТЕ ENDPOINT (например, POST /2fa/setup)

4. НАЖМИТЕ "Try it out"

5. ВВЕДИТЕ ПАРАМЕТРЫ:
   
   Для POST /2fa/setup:
   - user_id: test_user (в поле "user_id")
   - Request body (нажмите "Schema" или введите JSON):
     {
       "method": "totp",
       "email": "test@example.com"
     }

6. НАЖМИТЕ "Execute"

7. УВИДИТЕ РЕЗУЛЬТАТ:
   - qr_code (base64 изображение)
   - secret (секретный ключ)
   - backup_codes (10 кодов)


📋 ПРИМЕРЫ:
===========

ПРИМЕР 1: Настройка 2FA (Google Authenticator)
-----------------------------------------------
POST /2fa/setup

Параметры:
- user_id: test_user

Body:
{
  "method": "totp",
  "email": "test@example.com"
}

Результат:
✅ QR код для сканирования
✅ Backup коды для сохранения


ПРИМЕР 2: Проверка статуса
---------------------------
GET /2fa/status

Параметры:
- user_id: test_user

Результат:
{
  "enabled": false,
  "setup_required": true
}


ПРИМЕР 3: Верификация кода
---------------------------
POST /2fa/verify

Параметры:
- user_id: test_user

Body:
{
  "code": "123456"
}

(код из Google Authenticator)


ПРИМЕР 4: Отправить код (SMS/Email)
------------------------------------
POST /2fa/send-code

Параметры:
- user_id: test_user

Результат:
✅ Код отправлен (в production)


⚠️ ВАЖНО:
=========

1. ВСЕГДА вводите user_id в поле параметров!
   - Для GET запросов: в поле "user_id"
   - Для POST запросов: в поле "user_id" + в "Request body"

2. Для демо используйте: test_user

3. QR код - это base64 изображение
   - Скопируйте значение "qr_code"
   - Откройте в браузере или используйте Google Authenticator

4. Backup коды сохраните!
   - Это одноразовые коды для восстановления
   - Храните в безопасном месте


🔍 ЕСЛИ НЕ ВИДИТЕ ПОЛЕ user_id:
==============================
1. Перезапустите backend сервер
2. Обновите страницу Swagger (F5)
3. Убедитесь, что используете последнюю версию кода


✅ ГОТОВО!
==========
Теперь всё должно работать правильно!
