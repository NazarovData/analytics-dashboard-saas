========================================
  САМЫЙ ПРОСТОЙ СПОСОБ ЗАПУСКА
========================================

ЗАПУСК:
-------
Двойной клик по файлу: ПУСК.bat


ЧТО ОН ДЕЛАЕТ:
--------------
1. Проверяет и устанавливает зависимости
2. Запускает бэкенд (минимизированное окно)
3. Запускает фронтенд (минимизированное окно)
4. Ждет 60 секунд
5. Проверяет готовность серверов через PowerShell
6. Открывает браузеры Edge ТОЛЬКО когда серверы готовы


ОСОБЕННОСТИ:
------------
✅ Окна серверов минимизированы (не мешают)
✅ PowerShell проверяет готовность до 60 секунд
✅ Браузеры открываются только когда серверы готовы
✅ Всё в одном окне - просто и понятно


ЕСЛИ НЕ РАБОТАЕТ:
-----------------
1. Откройте Диспетчер задач (Ctrl+Shift+Esc)
2. Найдите процессы python.exe и node.exe
3. Если их нет - серверы не запустились
4. Проверьте что Python и Node.js установлены


АЛЬТЕРНАТИВА:
-------------
Если ПУСК.bat не работает, используйте:
ФИНАЛЬНЫЙ_ЗАПУСК.bat
