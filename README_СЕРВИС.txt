========================================
  ЗАПУСК ЧЕРЕЗ СЕРВИС/ФОНОВЫЕ ПРОЦЕССЫ
========================================

СПОСОБ 1 (ПРОСТОЙ СЕРВИС):
---------------------------
Запустите файл: СЕРВИС_ЗАПУСК.bat

Он запустит серверы как фоновые процессы:
- Бэкенд в фоне (порт 8000)
- Фронтенд в фоне (порт 3000)
- Автоматически откроет Edge браузеры


СПОСОБ 2 (ПРОВЕРКА):
--------------------
Запустите файл: ПРОВЕРКА_СЕРВИСОВ.bat

Он проверит:
- Работают ли процессы
- Открыты ли порты
- Доступны ли серверы


СПОСОБ 3 (ОСТАНОВКА):
---------------------
Запустите файл: ОСТАНОВИТЬ_СЕРВИСЫ.bat

Он остановит все фоновые процессы серверов


СПОСОБ 4 (АВТОЗАПУСК):
----------------------
Запустите файл: АВТОЗАПУСК_ПЛАНИРОВЩИК.bat

Он создаст задачу в планировщике Windows для автозапуска
при входе в систему


========================================
  ОТЛИЧИЯ ОТ ОБЫЧНОГО ЗАПУСКА:
========================================

Обычный запуск (СТАРТ.bat):
- Открывает окна cmd для каждого сервера
- Видны логи в реальном времени
- Легко остановить (закрыть окна)

Сервис запуск (СЕРВИС_ЗАПУСК.bat):
- Запускает процессы в фоне
- Логи сохраняются в файлы (backend.log, frontend.log)
- Не видно окон процессов
- Нужно использовать ОСТАНОВИТЬ_СЕРВИСЫ.bat для остановки


========================================
  ФАЙЛЫ ЛОГОВ:
========================================

- backend.log - логи бэкенда
- frontend.log - логи фронтенда

Откройте их для просмотра ошибок если что-то не работает


========================================
  РЕКОМЕНДАЦИЯ:
========================================

Для разработки используйте: СТАРТ.bat
Для фонового запуска используйте: СЕРВИС_ЗАПУСК.bat
