🔐 ПРОСТАЯ ИНСТРУКЦИЯ ПО 2FA
============================

✅ ИСПРАВЛЕНО! Теперь проще использовать!


📋 ШАГ 1: ПЕРЕЗАПУСТИТЕ BACKEND
===============================
1. Остановите сервер (Ctrl+C)
2. Запустите снова:
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
3. Обновите Swagger (F5)


📋 ШАГ 2: НАСТРОЙТЕ 2FA
=======================

POST /2fa/setup

1. Нажмите "Try it out"
2. В "Request body" введите:

{
  "user_id": "test_user",
  "method": "totp",
  "email": "test@example.com"
}

3. Нажмите "Execute"

✅ Получите QR код и backup коды!


📋 ШАГ 3: ОТСКАНИРУЙТЕ QR КОД
=============================

1. Скопируйте значение "qr_code" из ответа
2. Откройте Google Authenticator
3. Нажмите "+" → "Сканировать QR код"
4. Вставьте скопированный qr_code


📋 ШАГ 4: ВЕРИФИЦИРУЙТЕ
=======================

POST /2fa/verify

1. Получите код из Google Authenticator (6 цифр)
2. В "Request body" введите:

{
  "user_id": "test_user",
  "code": "123456"
}

3. Нажмите "Execute"

✅ Код верифицирован!


📋 ДРУГИЕ ENDPOINTS:
===================

GET /2fa/status
- Параметры: user_id = test_user

DELETE /2fa/disable
- Параметры: user_id = test_user

POST /2fa/send-code
- Параметры: user_id = test_user

POST /2fa/regenerate-backup-codes
- Параметры: user_id = test_user


✅ ТЕПЕРЬ ВСЁ ПРОЩЕ:
===================

Для POST запросов:
- user_id в Request body (в JSON)
- Не нужно вводить отдельно!

Для GET/DELETE:
- user_id в Parameters (query)
