✅ Добавлена кнопка "Данные" для просмотра записей из PostgreSQL!

═══════════════════════════════════════════════════════════════
  🛑 ШАГ 1: ОСТАНОВИТЕ FRONTEND
═══════════════════════════════════════════════════════════════

1. Найдите окно CMD/PowerShell где запущен frontend
2. Нажмите Ctrl+C
3. Дождитесь остановки сервера

═══════════════════════════════════════════════════════════════
  🚀 ШАГ 2: ЗАПУСТИТЕ FRONTEND ЗАНОВО
═══════════════════════════════════════════════════════════════

Дважды кликните файл:

    start_frontend.bat

Или выполните в CMD:

    cd frontend
    npm run dev

═══════════════════════════════════════════════════════════════
  ✅ ШАГ 3: ОТКРОЙТЕ ИНТЕГРАЦИИ
═══════════════════════════════════════════════════════════════

1. Откройте: http://localhost:3000/integrations

2. Найдите вашу интеграцию PostgreSQL:
   
   PostgreSQL
   20 записей • Синхр: 28.01.2026, 02:07:04
   Подключено

3. Нажмите новую кнопку "Данные" (голубая, с иконкой таблицы)

4. Увидите таблицу с вашими данными!
