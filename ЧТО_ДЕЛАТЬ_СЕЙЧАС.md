# 🚀 ЧТО ДЕЛАТЬ СЕЙЧАС - Решение проблемы localhost:3000

## ❌ Проблема:
`ERR_CONNECTION_REFUSED` на http://localhost:3000

Это значит что **frontend сервер не запущен**.

---

## ✅ РЕШЕНИЕ (3 простых шага):

### ШАГ 1: Закройте все окна командной строки

Закройте все открытые окна с ошибками или старыми процессами.

---

### ШАГ 2: Запустите Frontend

**Дважды кликните на файл:**
```
ЗАПУСТИТЬ_FRONTEND.bat
```

**ИЛИ** откройте командную строку и выполните:
```bash
cd frontend
npm install
npm run dev
```

---

### ШАГ 3: Дождитесь запуска

В консоли должно появиться:
```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:3000/
```

**ТОЛЬКО ПОСЛЕ ЭТОГО** откройте браузер!

---

## 🎯 Альтернатива: Запустить все сразу

Если хотите запустить backend и frontend вместе:

**Дважды кликните:**
```
start_all.bat
```

Это запустит оба сервера автоматически.

---

## ⚠️ ВАЖНО:

1. **Не закрывайте окно командной строки** пока работает сервер
2. **Дождитесь сообщения** "Local: http://localhost:3000" перед открытием браузера
3. **Если порт занят** - Vite использует другой порт (3001, 3002 и т.д.) - смотрите в консоли!

---

## 🔍 Если не работает:

1. Проверьте что Node.js установлен:
   ```bash
   node --version
   ```

2. Проверьте что npm установлен:
   ```bash
   npm --version
   ```

3. Установите зависимости вручную:
   ```bash
   cd frontend
   npm install
   ```

4. Запустите снова:
   ```bash
   npm run dev
   ```

---

## ✅ После успешного запуска:

1. Откройте браузер: http://localhost:3000
2. Должна открыться страница входа BizPulse PRO
3. Нажмите "Sign up" для регистрации
