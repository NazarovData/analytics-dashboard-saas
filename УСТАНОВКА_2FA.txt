🔐 УСТАНОВКА ЗАВИСИМОСТЕЙ ДЛЯ 2FA
========================================

📍 ГДЕ УСТАНОВИТЬ:
------------------
Зависимости устанавливаются в ВИРТУАЛЬНОЕ ОКРУЖЕНИЕ (venv) проекта.

📂 ПУТЬ К ПРОЕКТУ:
------------------
C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS

🚀 КАК УСТАНОВИТЬ:
------------------

1️⃣ Откройте PowerShell или CMD в папке проекта

2️⃣ Активируйте виртуальное окружение:
   venv\Scripts\activate

3️⃣ Установите зависимости:
   pip install pyotp qrcode[pil] pillow

4️⃣ Или установите все зависимости из requirements.txt:
   pip install -r requirements.txt

✅ ГОТОВО!
----------
После установки зависимости будут в папке:
venv\Lib\site-packages\

📋 ЧТО УСТАНАВЛИВАЕТСЯ:
-----------------------
- pyotp      → Генерация TOTP кодов (Google Authenticator)
- qrcode[pil] → Создание QR кодов для настройки 2FA
- Pillow     → Работа с изображениями (для QR кодов)

🔍 ПРОВЕРКА УСТАНОВКИ:
---------------------
Выполните в PowerShell (после активации venv):
python -c "import pyotp; import qrcode; print('✅ Всё установлено!')"

Если выводит "✅ Всё установлено!" - всё правильно!

⚠️ ЕСЛИ ОШИБКА:
---------------
- Убедитесь, что venv активирован (должно быть (venv) в начале строки)
- Попробуйте: pip install --upgrade pip
- Затем: pip install pyotp qrcode[pil] pillow

📝 ПРИМЕЧАНИЕ:
--------------
Зависимости устанавливаются ЛОКАЛЬНО в папку venv проекта,
НЕ в системный Python.
