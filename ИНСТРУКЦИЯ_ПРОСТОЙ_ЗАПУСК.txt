========================================
  ПРОСТОЙ СПОСОБ ЗАПУСКА
========================================

ШАГ 1: Запустите ЗАПУСК.bat
---------------------------
Просто двойной клик по файлу ЗАПУСК.bat

Скрипт автоматически:
- Проверит окружение
- Запустит бэкенд (порт 8000)
- Запустит фронтенд (порт 3000)
- Проверит готовность серверов
- Откроет браузеры Edge когда серверы будут готовы


ШАГ 2: Подождите
---------------------------
Скрипт будет проверять готовность серверов каждые 3 секунды
Браузеры откроются автоматически когда серверы будут готовы


ШАГ 3: Если браузеры не открылись
---------------------------
1. Проверьте окна "Backend" и "Frontend" - запущены ли они?
2. Есть ли ошибки в этих окнах?
3. Запустите ПРОВЕРКА_СЕРВЕРОВ.bat для проверки

========================================
  РЕШЕНИЕ ПРОБЛЕМ
========================================

Проблема: ERR_CONNECTION_REFUSED
Решение:
1. Убедитесь что серверы запущены (проверьте окна)
2. Подождите больше времени (30-60 секунд)
3. Проверьте что порты 3000 и 8000 свободны
4. Запустите ПРОВЕРКА_СЕРВЕРОВ.bat

Проблема: Серверы не запускаются
Решение:
1. Проверьте что Python установлен: python --version
2. Проверьте что Node.js установлен: node --version
3. Проверьте что venv существует: venv\Scripts\activate.bat
4. Установите зависимости: pip install -r requirements.txt
