# 🗄️ Настройка базы данных PostgreSQL

## Шаг 1: Создать базу данных

В psql выполните:

```sql
CREATE DATABASE analitix_ai;
```

Или через командную строку:

```cmd
createdb -U postgres analitix_ai
```

## Шаг 2: Установить зависимости

```cmd
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS"
venv\Scripts\activate
pip install -r requirements.txt
```

## Шаг 3: Инициализировать таблицы

```cmd
python -m app.core.init_db
```

Должно появиться:
```
✅ База данных успешно инициализирована!
```

## Шаг 4: Настроить DATABASE_URL (опционально)

Если база не на localhost или другие credentials:

Создайте файл `.env`:
```
DATABASE_URL=postgresql://postgres:ваш_пароль@localhost:5432/analitix_ai
```

## Готово! 🎉

Теперь все данные сохраняются в PostgreSQL:

- ✅ Заявки с Landing Page
- ✅ Аналитика

# 📊 BI Аналитика для PostgreSQL

## Как использовать:

1. Подключите PostgreSQL
2. Выберите таблицу
3. Нажмите **"BI Анализ (автоматически)"** - система сама построит графики
4. Или используйте **BI Предложения** - готовые SQL запросы
5. Или напишите свой SQL запрос

## Возможности:

- 📈 Автоматическое построение графиков
- 🥧 Распределение по категориям
- 📊 Временные ряды
- 🏆 Топ значения
- 📈 Статистика (среднее, медиана, мин, макс)
