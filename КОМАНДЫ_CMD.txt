========================================
  ПРИМЕЧАНИЯ:
========================================

- Замените путь "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS" 
  на ваш реальный путь к проекту

- Убедитесь что:
  * Python установлен и venv активирован
  * Node.js установлен
  * Зависимости установлены (npm install в папке frontend)

  * Изменения во фронтенде - страница обновится сама
  * Изменения в бэкенде - сервер перезагрузится сам
