# 💻 Локальный запуск (если нет Railway URL)

## 🎯 Альтернатива: Запустите локально

Если у вас нет Railway URL, можете запустить проект локально:

---

## 📋 ШАГ 1: Запустите Backend локально

### 1. Установите зависимости

```bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте его
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройте PostgreSQL

Установите PostgreSQL или используйте Docker:

```bash
docker run -d \
  --name postgres \
  -e POSTGRES_USER=bizpulse \
  -e POSTGRES_PASSWORD=bizpulse_password \
  -e POSTGRES_DB=bizpulse_db \
  -p 5432:5432 \
  postgres:15-alpine
```

### 3. Настройте .env

Создайте файл `.env`:

```env
DATABASE_URL=postgresql+asyncpg://bizpulse:bizpulse_password@localhost:5432/bizpulse_db
DATABASE_URL_SYNC=postgresql://bizpulse:bizpulse_password@localhost:5432/bizpulse_db
SECRET_KEY=your-secret-key-here
DEBUG=True
```

### 4. Запустите миграции

```bash
alembic upgrade head
```

### 5. Запустите Backend

```bash
uvicorn app.main:app --reload
```

Backend будет доступен на: **http://localhost:8000**

---

## 📋 ШАГ 2: Запустите Frontend локально

### 1. Перейдите в папку frontend

```bash
cd frontend
```

### 2. Установите зависимости

```bash
npm install
```

### 3. Создайте .env файл

Создайте `frontend/.env`:

```env
VITE_API_URL=http://localhost:8000/api/v1
```

### 4. Запустите Frontend

```bash
npm run dev
```

Frontend будет доступен на: **http://localhost:3000**

---

## ✅ Готово!

Откройте: **http://localhost:3000**

Вы увидите страницу входа с "BizPulse PRO".

---

## 🔍 Проверка

1. Backend: http://localhost:8000/health → `{"status": "healthy"}`
2. Frontend: http://localhost:3000 → страница входа
3. API Docs: http://localhost:8000/docs → Swagger документация

3. Посмотрите аналитику
