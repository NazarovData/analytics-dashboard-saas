## 🥇 ВАРИАНТ 1: Railway.app (РЕКОМЕНДУЮ)

### Почему Railway:
- ✅ **Полностью бесплатно** ($5 кредитов каждый месяц)
- ✅ **Простой деплой** - один клик из GitHub
- ✅ **PostgreSQL включен** - бесплатно
- ✅ **Автоматический HTTPS**
- ✅ **Поддержка Docker и Python**
- ✅ **Frontend и Backend вместе**

### Как задеплоить:

#### ШАГ 1: Подготовка
1. Зарегистрируйтесь на https://railway.app (через GitHub)
2. Установите Railway CLI (опционально):
   ```bash
   npm i -g @railway/cli
   ```

#### ШАГ 2: Создайте репозиторий на GitHub
1. Создайте новый репозиторий на GitHub
2. Загрузите ваш код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/ваш-username/ваш-репозиторий.git
   git push -u origin main
   ```

#### ШАГ 3: Деплой на Railway
1. Зайдите на https://railway.app
2. Нажмите **"New Project"**
3. Выберите **"Deploy from GitHub repo"**
4. Выберите ваш репозиторий
5. Railway автоматически определит Python проект

#### ШАГ 4: Добавьте PostgreSQL
1. В проекте нажмите **"+ New"**
2. Выберите **"Database"** → **"PostgreSQL"**
3. Railway создаст базу данных автоматически

#### ШАГ 5: Настройте переменные окружения
1. В настройках проекта → **"Variables"**
2. Добавьте:
   ```
   DATABASE_URL=<автоматически из PostgreSQL>
   SECRET_KEY=<сгенерируйте случайный ключ>
   ENVIRONMENT=production
   ```

#### ШАГ 6: Деплой Frontend
1. Создайте **новый сервис** в том же проекте
2. Выберите **"GitHub Repo"** → ваш репозиторий
3. Установите **Root Directory**: `frontend`
4. **Build Command**: `npm install && npm run build`
5. **Start Command**: `npm run preview` или используйте статический хостинг

**ИЛИ** используйте Vercel для Frontend (см. ниже)

## 🥈 ВАРИАНТ 2: Render.com

### Почему Render:
- ✅ **Бесплатный tier** (с ограничениями)
- ✅ **PostgreSQL бесплатно**
- ✅ **Автоматический деплой из GitHub**
- ⚠️ Приложение "засыпает" после 15 минут бездействия (бесплатный tier)

### Как задеплоить:

1. Зарегистрируйтесь на https://render.com
2. Подключите GitHub репозиторий
3. Создайте **Web Service** для Backend:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
4. Создайте **PostgreSQL Database**
5. Создайте **Static Site** для Frontend:
   - **Build Command**: `cd frontend && npm install && npm run build`
   - **Publish Directory**: `frontend/dist`

## 🥉 ВАРИАНТ 3: Vercel (Frontend) + Railway (Backend)

### Почему этот вариант:
- ✅ **Vercel** - лучший для Frontend (React/Vite)
- ✅ **Railway** - лучший для Backend (Python/FastAPI)
- ✅ **Оба бесплатные**
- ✅ **Отличная производительность**

### Как задеплоить:

#### Frontend на Vercel:
1. Зайдите на https://vercel.com
2. Импортируйте GitHub репозиторий
3. Установите:
   - **Framework Preset**: Vite
   - **Root Directory**: `frontend`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Добавьте переменную окружения:
   ```
   VITE_API_URL=https://ваш-backend.railway.app/api/v1
   ```

#### Backend на Railway:
См. ВАРИАНТ 1 выше

## 🆓 ВАРИАНТ 4: Fly.io

### Почему Fly.io:
- ✅ **Бесплатный tier** (3 shared-cpu VMs)
- ✅ **PostgreSQL бесплатно**
- ✅ **Глобальная сеть**

### Как задеплоить:

1. Установите Fly CLI:
   ```bash
   powershell -Command "iwr https://fly.io/install.ps1 -useb | iex"
   ```

2. Зарегистрируйтесь:
   ```bash
   fly auth signup
   ```

3. Создайте приложение:
   ```bash
   fly launch
   ```

4. Добавьте PostgreSQL:
   ```bash
   fly postgres create
   fly postgres attach <db-name>
   ```
