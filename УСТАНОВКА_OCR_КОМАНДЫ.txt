ШАГ 1: Активация виртуального окружения
─────────────────────────────────────────
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS"
venv\Scripts\activate.bat

ШАГ 2: Установка библиотек (выберите нужные)
──────────────────────────────────────────────

[1] pytesseract (обёртка для Tesseract OCR)
────────────────────────────────────────────
python -m pip install --upgrade pip
python -m pip install pytesseract==0.3.10

⚠️  ВАЖНО: Для работы нужен Tesseract OCR
   Скачайте с: https://github.com/UB-Mannheim/tesseract/wiki
   Или используйте EasyOCR (вариант 4)


[2] opencv-python (обработка изображений)
─────────────────────────────────────────
python -m pip install --upgrade pip
python -m pip install opencv-python==4.8.1.78


[3] pdf2image (конвертация PDF в изображения)
─────────────────────────────────────────────
python -m pip install --upgrade pip
python -m pip install pdf2image==1.16.3

⚠️  ВАЖНО: Для работы нужен poppler
   Windows: https://github.com/oschwartz10612/poppler-windows/releases
   Или используйте только изображения (JPG/PNG)


[4] easyocr (OCR с поддержкой таджикского языка)
─────────────────────────────────────────────────
python -m pip install --upgrade pip
python -m pip install easyocr==1.7.0

⚠️  Это большая библиотека (~500MB), установка может занять время
✅ Поддержка языков: русский, английский, таджикский


[5] Установить ВСЕ библиотеки сразу
───────────────────────────────────
python -m pip install --upgrade pip
python -m pip install pytesseract==0.3.10
python -m pip install opencv-python==4.8.1.78
python -m pip install pdf2image==1.16.3
python -m pip install easyocr==1.7.0
