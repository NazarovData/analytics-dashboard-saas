## 📊 Как посмотреть данные

### Способ 1: Через кнопку "Данные" (НОВАЯ ФУНКЦИЯ!)

1. На странице интеграций найдите вашу интеграцию PostgreSQL
2. Нажмите кнопку **"Данные"** (с иконкой таблицы)
3. Откроется модальное окно с таблицей данных
4. Вы увидите все 20 записей из PostgreSQL
5. Нажмите **"Открыть в дашборде"** для анализа

### Способ 2: Через API напрямую

Откройте в браузере:
```
http://localhost:8000/api/v1/sync/{integration_id}/data
```

Где `{integration_id}` - это ID вашей интеграции (начинается с `int_`)

### Способ 3: Через дашборд

1. Перейдите на главную страницу: `http://localhost:3000/dashboard`
2. Данные из PostgreSQL автоматически доступны для анализа
3. Выберите нужные метрики и визуализации

## 📋 Структура данных PostgreSQL

Ваши данные из таблицы `sales`:

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | INTEGER | ID записи |
| date | DATE | Дата продажи |
| product | VARCHAR | Название товара |
| quantity | INTEGER | Количество |
| price | DECIMAL | Цена |
| customer_id | VARCHAR | ID клиента |
| region | VARCHAR | Регион |
| category | VARCHAR | Категория |
| cost | DECIMAL | Себестоимость |
| profit | DECIMAL | Прибыль |
| total | DECIMAL | Итого |
| created_at | TIMESTAMP | Дата создания |
