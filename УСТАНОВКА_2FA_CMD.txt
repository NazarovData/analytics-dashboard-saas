🔐 УСТАНОВКА 2FA ЧЕРЕЗ CMD (КОМАНДНАЯ СТРОКА)
============================================

📍 ШАГ 1: Откройте CMD (командную строку)
------------------------------------------
Windows + R → введите "cmd" → Enter

ИЛИ

Пуск → поиск "cmd" → Запуск от имени администратора

📍 ШАГ 2: Перейдите в папку проекта
------------------------------------
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS"

📍 ШАГ 3: Активируйте виртуальное окружение
--------------------------------------------
venv\Scripts\activate.bat

✅ Должно появиться (venv) в начале строки!

📍 ШАГ 4: Установите зависимости
---------------------------------
pip install pyotp qrcode[pil] Pillow

📍 ШАГ 5: Проверьте установку
-------------------------------
python -c "import pyotp; import qrcode; print('✅ Всё установлено!')"

✅ Если видите "✅ Всё установлено!" - всё готово!

============================================

⚡ БЫСТРЫЙ СПОСОБ (автоматический):
-----------------------------------
Дважды кликните на файл: УСТАНОВКА_2FA_CMD.bat

Файл автоматически выполнит все команды!

============================================

📋 ВСЕ КОМАНДЫ ОДНОЙ СТРОКОЙ:
-----------------------------
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS" && venv\Scripts\activate.bat && pip install pyotp qrcode[pil] Pillow && python -c "import pyotp; import qrcode; print('✅ Готово!')"

============================================

❓ ЧТО УСТАНАВЛИВАЕТСЯ:
-----------------------
- pyotp      → Генерация кодов для Google Authenticator
- qrcode[pil] → Создание QR кодов
- Pillow     → Работа с изображениями

📍 ГДЕ УСТАНАВЛИВАЕТСЯ:
----------------------
Зависимости устанавливаются в:
C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS\venv\Lib\site-packages\

НЕ в системный Python, а в виртуальное окружение проекта!

============================================

⚠️ ЕСЛИ ОШИБКИ:
---------------
1. Убедитесь, что venv активирован ((venv) в начале строки)
2. Обновите pip: python -m pip install --upgrade pip
3. Установите по одной:
   pip install pyotp
   pip install qrcode
   pip install Pillow
