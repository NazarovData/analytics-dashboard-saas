========================================
  ПРОСТОЙ ЗАПУСК С АВТООТКРЫТИЕМ БРАУЗЕРА
========================================

ЗАПУСК:
-------
Просто запустите: ЗАПУСК_ПРОСТОЙ.bat
(двойной клик)

ЧТО ПРОИСХОДИТ:
---------------
1. Проверяется окружение (Python, Node.js)
2. Создается venv если нужно
3. Устанавливаются зависимости если нужно
4. Запускается бэкенд (порт 8000)
5. Запускается фронтенд (порт 3000)
6. ПРОВЕРЯЕТСЯ готовность серверов
7. Браузеры открываются ТОЛЬКО когда серверы готовы


ВАЖНО:
------
Скрипт ЖДЕТ пока серверы будут готовы перед открытием браузера!
Это может занять 30-60 секунд.

Не закрывайте окна "Backend" и "Frontend" - они должны быть открыты!


ЕСЛИ БРАУЗЕРЫ НЕ ОТКРЫЛИСЬ:
---------------------------
Запустите: ПРОСТОЙ_ОТКРЫТЬ.bat


ЕСЛИ ВИДИТЕ ОШИБКУ ERR_CONNECTION_REFUSED:
------------------------------------------
1. Проверьте окна "Backend" и "Frontend"
2. Должны быть сообщения:
   - Backend: "Uvicorn running on http://0.0.0.0:8000"
   - Frontend: "Local: http://localhost:3000"
3. Если есть ошибки - покажите их мне
4. Подождите еще 30-60 секунд
5. Обновите страницу в браузере (F5)


ПРОВЕРКА:
---------
После запуска проверьте:
- Окно "Backend" открыто и показывает "Uvicorn running"
- Окно "Frontend" открыто и показывает "Local: http://localhost:3000"
- Прошло минимум 30 секунд после запуска
