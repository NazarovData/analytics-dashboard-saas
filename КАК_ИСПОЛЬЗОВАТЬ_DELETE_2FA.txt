❌ ОШИБКА: "Required field is not provided"
===========================================

✅ РЕШЕНИЕ: Нужно ввести user_id в поле параметров!


📋 КАК ИСПОЛЬЗОВАТЬ DELETE /2fa/disable:
========================================

ШАГ 1: Найдите endpoint в Swagger
-----------------------------------
1. Откройте: http://localhost:8000/docs
2. Найдите раздел "2fa"
3. Найдите "DELETE /2fa/disable"
4. Нажмите "Try it out"


ШАГ 2: ВВЕДИТЕ user_id
-----------------------
В разделе "Parameters" вы увидите:

┌─────────────────────────────────┐
│ Parameters                      │
├─────────────────────────────────┤
│ user_id * (required)            │
│ [_________________]             │ ← ВОТ СЮДА ВВЕДИТЕ!
└─────────────────────────────────┘

1. Найдите поле "user_id"
2. Введите: test_user
3. Нажмите "Execute"


✅ ДОЛЖНО БЫТЬ ТАК:
==================

DELETE /2fa/disable

Parameters:
┌─────────────────────────────┐
│ user_id *                   │
│ test_user                   │ ← Введено здесь
└─────────────────────────────┘

[Execute] ← Нажать здесь


❌ НЕ ТАК:
==========
┌─────────────────────────────┐
│ user_id *                   │
│ [пусто]                     │ ← ПУСТО! Ошибка!
└─────────────────────────────┘

==============================

1. GET /2fa/status
   Parameters:
   - user_id: test_user
   → Execute

2. POST /2fa/setup
   Parameters:

   Request body:

     "method": "totp",
     "email": "test@example.com"
   }
   → Execute

3. POST /2fa/verify
   Parameters:

   {

   }
   → Execute

4. POST /2fa/send-code
   Parameters:
   - user_id: test_user
   → Execute

5. DELETE /2fa/disable ← ВОТ ЭТОТ!
   Parameters:
   - user_id: test_user ← ВВЕДИТЕ СЮДА!
   → Execute

6. POST /2fa/regenerate-backup-codes
   Parameters:
   - user_id: test_user
   → Execute


⚠️ ВАЖНО:
=========

1. ВСЕГДА заполняйте поле user_id!
   - Даже если оно пустое по умолчанию
   - Введите: test_user (или любой другой ID)

2. Поле помечено звёздочкой (*) = обязательное!

3. Если не вводите user_id → ошибка 422

4. Для всех endpoints нужен user_id в параметрах


✅ ПРАВИЛЬНАЯ ПОСЛЕДОВАТЕЛЬНОСТЬ:
=================================

1. Нажмите "Try it out"
2. Увидите поле "Parameters" с "user_id"
3. Введите в поле: test_user
4. (Для POST) Введите данные в "Request body"
5. Нажмите "Execute"
6. Увидите результат!


🔍 ЕСЛИ НЕ ВИДИТЕ ПОЛЕ user_id:
===============================

1. Убедитесь, что нажали "Try it out"
2. Прокрутите вниз - поле может быть ниже
3. Обновите страницу (F5)
4. Перезапустите backend сервер
