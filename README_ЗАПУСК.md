```

- ✅ Показывает прогресс каждого шага
- ✅ Автоматически устанавливает зависимости
- ✅ Открывает браузер после запуска
- ✅ Работает даже если что-то уже установлено

## 🎯 СПОСОБ 2: Простой

**Дважды кликните:**

ЗАПУСК_ПРОСТОЙ.bat
```

Быстрый запуск без проверок (если все уже установлено).

---

## 🎯 СПОСОБ 3: С настройками

**Дважды кликните:**
```
ЗАПУСК.bat
```

С дополнительными проверками и настройками.

---

## ⏳ Что происходит:

1. **0-10 секунд** - Запуск базы данных (Docker)
2. **10-20 секунд** - Запуск Backend сервера
3. **20-80 секунд** - Установка зависимостей Frontend (только первый раз)
4. **80-90 секунд** - Ожидание полного запуска
5. **90 секунд** - Автоматическое открытие браузера

---

## ✅ После запуска:

1. Откроется **2 окна командной строки**:
   - "BizPulse Backend" - не закрывайте!
   - "BizPulse Frontend" - не закрывайте!

2. Откроется **браузер** с:
   - http://localhost:3000 - Frontend (главная страница)
   - http://localhost:8000/docs - Backend API (документация)

3. На странице входа:
   - Нажмите **"Sign up"**
   - Зарегистрируйтесь
   - Войдите в систему

---

## ⚠️ Если не работает:

### Проблема: Страница не открывается

**Решение:**
1. Подождите еще 30 секунд
2. Обновите страницу (F5)
3. Или откройте вручную: http://localhost:3000

### Проблема: Окна не открываются

**Решение:**
1. Откройте командную строку вручную
2. Перейдите в папку проекта
3. Запустите:
   ```bash
   start_backend.bat
   ```
   В другом окне:
   ```bash
   start_frontend.bat
   ```

### Проблема: Ошибки при установке

**Решение:**
1. Убедитесь что установлены:
   - Python 3.11+ (https://www.python.org/downloads/)
   - Node.js 18+ (https://nodejs.org/)
   - Docker Desktop (https://www.docker.com/products/docker-desktop)

2. Запустите `setup.bat` для проверки
