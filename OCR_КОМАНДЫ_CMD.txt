ШАГ 1: Перейти в папку проекта и активировать venv
───────────────────────────────────────────────────────────────

cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS"
venv\Scripts\activate.bat


ШАГ 2: Обновить pip (обязательно!)
───────────────────────────────────────────────────────────────

python -m pip install --upgrade pip


ШАГ 3: Установить библиотеки (выберите нужные)
───────────────────────────────────────────────────────────────

[1] pytesseract (обёртка для Tesseract OCR)
────────────────────────────────────────────
python -m pip install pytesseract==0.3.10


[2] opencv-python (обработка изображений) - ОБЯЗАТЕЛЬНО!
───────────────────────────────────────────────────────────
python -m pip install opencv-python==4.8.1.78


[3] pdf2image (конвертация PDF в изображения)
──────────────────────────────────────────────
python -m pip install pdf2image==1.16.3


[4] easyocr (OCR с поддержкой таджикского) - РЕКОМЕНДУЕТСЯ!
──────────────────────────────────────────────────────────────
python -m pip install easyocr==1.7.0


[5] Установить ВСЕ сразу (скопируйте все команды подряд)
─────────────────────────────────────────────────────────
python -m pip install pytesseract==0.3.10
python -m pip install opencv-python==4.8.1.78
python -m pip install pdf2image==1.16.3
python -m pip install easyocr==1.7.0
