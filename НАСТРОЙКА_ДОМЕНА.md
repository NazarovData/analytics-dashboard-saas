# Настройка домена для проекта

## Текущая конфигурация

Сейчас проект настроен для работы на `localhost`. Для работы с доменом нужно выполнить следующие шаги.

## Шаги настройки домена

### 1. Настройка бэкенда (FastAPI)

В файле `app/main.py` уже настроен CORS для работы с любыми доменами:
```python
allow_origins=["*"]  # Разрешает все домены
```

Для production рекомендуется указать конкретные домены:
```python
allow_origins=[
    "https://ваш-домен.com",
    "https://www.ваш-домен.com",
    "http://localhost:3000",  # Для разработки
]
```

### 2. Настройка фронтенда

Создайте файл `frontend/.env.production`:
```
VITE_API_URL=https://api.ваш-домен.com/api/v1
```

Или для разработки `frontend/.env`:
```
VITE_API_URL=http://localhost:8000/api/v1
```

### 3. Настройка Vite для production

В `frontend/vite.config.ts` добавьте настройки для production:
```typescript
export default defineConfig({
  // ... существующие настройки
  server: {
    port: 3000,
    host: true,  // Разрешает доступ с других устройств
    strictPort: false,
  },
  preview: {
    port: 3000,
    host: true,
  },
})
```

### 4. Настройка Nginx (рекомендуется для production)

Создайте файл `nginx/nginx.conf`:
```nginx
server {
    listen 80;
    server_name ваш-домен.com www.ваш-домен.com;

    # Frontend
    location / {
        root /var/www/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # Backend API
    location /api {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 5. Настройка DNS

1. Добавьте A-запись в DNS вашего домена:
   - `ваш-домен.com` → IP вашего сервера
   - `www.ваш-домен.com` → IP вашего сервера
   - `api.ваш-домен.com` → IP вашего сервера (если используете поддомен)

2. Подождите распространения DNS (обычно 5-60 минут)

### 6. SSL сертификат (HTTPS)

Рекомендуется использовать Let's Encrypt:
```bash
sudo apt-get install certbot python3-certbot-nginx
sudo certbot --nginx -d ваш-домен.com -d www.ваш-домен.com
```

## Запуск с доменом

### Локальная разработка с доменом

1. Добавьте в `C:\Windows\System32\drivers\etc\hosts`:
```
127.0.0.1 ваш-домен.local
```

2. Запустите серверы как обычно

3. Откройте в браузере: `http://ваш-домен.local:3000`

### Production запуск

1. Соберите фронтенд:
```bash
cd frontend
npm run build
```

2. Запустите бэкенд:
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

3. Настройте Nginx для раздачи статики фронтенда

## Проверка работы

После настройки проверьте:
- `https://ваш-домен.com` - должен открываться фронтенд
- `https://ваш-домен.com/api/v1/health` - должен отвечать бэкенд
- `https://api.ваш-домен.com/docs` - документация API (если используете поддомен)

## Важные замечания

1. **CORS**: Убедитесь что домены в CORS совпадают с реальными доменами
2. **HTTPS**: Всегда используйте HTTPS в production
3. **Безопасность**: Не используйте `allow_origins=["*"]` в production
4. **Переменные окружения**: Используйте `.env` файлы для разных окружений
