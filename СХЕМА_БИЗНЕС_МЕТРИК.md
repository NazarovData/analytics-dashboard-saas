## 💰 Расчет LTV - 4 метода

```
ВХОДНЫЕ ДАННЫЕ
    │
    ├─► Метод 1: Простой LTV
    │   └─► LTV = Средняя выручка на клиента
    │
    ├─► Метод 2: LTV с маржой
    │   └─► LTV = ARPU × Gross Margin
    │
    ├─► Метод 3: Прогнозный LTV
    │   └─► LTV = (ARPU × Gross Margin) / Churn Rate
    │
    └─► Метод 4: Когортный LTV (самый точный)
        └─► LTV = AOV × Frequency × Lifespan × Margin
            │
            ▼
        ИТОГОВЫЙ LTV = Среднее из всех методов
```

## 🔄 Retention & Churn

```
КЛИЕНТЫ
    │
    ├─► Активные (покупали < 60 дней назад)
    │   └─► Retention Rate = Активные / Всего × 100%
    │
    └─► Ушедшие (не покупали > 60 дней)
        └─► Churn Rate = Ушедшие / Всего × 100%
        
        
Retention Rate + Churn Rate = 100%


Пример:
    Всего: 100 клиентов
    Активных: 76
    Ушедших: 24
    
    Retention Rate = 76%
    Churn Rate = 24%
```

## 📈 Формула когортного LTV (детально)

```
LTV = AOV × Purchase Frequency × Customer Lifespan × Gross Margin

где:

┌─────────────────────────────────────────────────────────┐
│ AOV (Average Order Value)                               │
│ = Общая выручка / Количество заказов                    │
│                                                         │
│ Пример: 475,000₽ / 150 заказов = 3,167₽               │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ Purchase Frequency (в месяц)                            │
│ = Заказов на клиента / Срок жизни в месяцах            │
│                                                         │
│ Пример: 3.2 заказа / 4 месяца = 0.8 заказов/мес       │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ Customer Lifespan (в месяцах)                           │
│ = Среднее время от первой до последней покупки         │
│                                                         │
│ Пример: 120 дней = 4 месяца                            │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ Gross Margin (валовая маржа)                            │
│ = (Выручка - Себестоимость) / Выручка                   │
│                                                         │
│ Пример: (475,000 - 285,000) / 475,000 = 0.40 (40%)    │
└─────────────────────────────────────────────────────────┘

ИТОГО:
LTV = 3,167₽ × 0.8 × 4 × 0.40 = 4,053₽
```

## 🚀 Путь улучшения метрик

```
ТЕКУЩЕЕ СОСТОЯНИЕ
    │
    ├─► LTV низкий?
    │   └─► Действия:
    │       ├─► Повысить средний чек (апсейл, кросс-сейл)
    │       ├─► Увеличить частоту покупок (email, лояльность)
    │       └─► Снизить churn (качество, сервис)
    │
    ├─► CAC высокий?
    │   └─► Действия:
    │       ├─► Оптимизировать рекламу (A/B тесты)
    │       ├─► Органический трафик (SEO, контент)
    │       └─► Реферальная программа
    │
    ├─► LTV/CAC < 3?
    │   └─► Действия:
    │       ├─► Увеличить LTV (см. выше)
    │       ├─► Снизить CAC (см. выше)
    │       └─► Улучшить конверсию
    │
    └─► Payback > 12 мес?
        └─► Действия:
            ├─► Быстрая монетизация (предоплата)
            ├─► Подписочная модель
            └─► Увеличить частоту покупок
            
            ▼
    УЛУЧШЕННОЕ СОСТОЯНИЕ
    (LTV/CAC > 3, Payback < 12 мес)
            │
            ▼
    🚀 МАСШТАБИРОВАНИЕ
```

## 🎯 Приоритеты действий

```
ВЫСОКИЙ ПРИОРИТЕТ (сделать сейчас)
    │
    ├─► LTV/CAC < 1
    │   └─► 🚨 КРИТИЧНО: Бизнес убыточный
    │
    ├─► Churn > 50%
    │   └─► 🚨 КРИТИЧНО: Массовый отток
    │
    └─► Payback > 24 мес
        └─► 🚨 КРИТИЧНО: Слишком долгая окупаемость

СРЕДНИЙ ПРИОРИТЕТ (сделать в ближайшее время)
    │
    ├─► LTV/CAC 1-2
    │   └─► ⚠️ Нужно улучшать
    │
    ├─► Churn 30-50%
    │   └─► ⚠️ Высокий отток
    │
    └─► Payback 12-24 мес
        └─► ⚠️ Долгая окупаемость

НИЗКИЙ ПРИОРИТЕТ (оптимизация)
    │
    ├─► LTV/CAC 2-3
    │   └─► ✅ Хорошо, но можно лучше
    │
    ├─► Churn 15-30%
    │   └─► ✅ Нормально, но можно снизить
    │
    └─► Payback 6-12 мес
        └─► ✅ Хорошо, но можно быстрее

ОТЛИЧНО (продолжать)
    │
    ├─► LTV/CAC > 3
    │   └─► 🌟 Масштабировать!
    │
    ├─► Churn < 15%
    │   └─► 🌟 Отличное удержание
    │
    └─► Payback < 6 мес
        └─► 🌟 Быстрая окупаемость
```
