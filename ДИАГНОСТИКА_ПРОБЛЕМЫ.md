# 🔍 Диагностика проблемы входа

## 🚨 Проблема: Не открывается после нажатия Login

Если вы вводите email и password, нажимаете Login, но ничего не происходит:

---

## ✅ ПРОВЕРКА 1: Откройте DevTools

1. Нажмите **F12** в браузере
2. Перейдите на вкладку **Console**
3. Попробуйте войти снова
4. **Посмотрите какие ошибки появляются**

Напишите какие ошибки вы видите!

---

## ✅ ПРОВЕРКА 2: Проверьте Network запросы

1. Нажмите **F12** в браузере
2. Перейдите на вкладку **Network**
3. Попробуйте войти снова
4. Найдите запрос к `/api/v1/auth/login`
5. **Посмотрите статус ответа**

Что показывает статус?
- ✅ 200 - успешно (но не перенаправляет)
- ❌ 401 - неверный пароль
- ❌ 404 - endpoint не найден
- ❌ 500 - ошибка сервера
- ❌ Failed - нет подключения к backend

---

## ✅ ПРОВЕРКА 3: Проверьте что Backend работает

Откройте в браузере:

```
https://your-backend.railway.app/health
```

Должен вернуться:
```json
{"status": "healthy"}
```

Если не работает - backend не запущен!

---

## ✅ ПРОВЕРКА 4: Проверьте vercel.json

Откройте файл `vercel.json` и проверьте:

```json
"destination": "https://ваш-railway-url.railway.app/api/$1"
```

Правильный ли Railway URL?

## 🆘 ВОЗМОЖНЫЕ ПРИЧИНЫ И РЕШЕНИЯ

### Причина 1: Backend не работает

**Симптомы:**
- Ошибка "Network Error" или "Failed to fetch"
- Статус запроса: Failed

**Решение:**
1. Проверьте Railway backend работает
2. Проверьте `https://your-backend.railway.app/health`
3. Если не работает - перезапустите в Railway

---

### Причина 2: Неправильный API URL

**Симптомы:**
- Ошибка 404 Not Found
- Запрос идет не туда

**Решение:**
1. Проверьте `vercel.json` - правильный ли Railway URL
2. Проверьте переменные окружения в Vercel: `VITE_API_URL=/api/v1`

---

### Причина 3: CORS ошибка

**Симптомы:**
- Ошибка "CORS policy" в Console
- Запрос блокируется

**Решение:**
1. В Railway добавьте переменную:
   ```
   BACKEND_CORS_ORIGINS=https://your-app.vercel.app
   ```
2. Перезапустите backend в Railway

---

### Причина 4: Неверный email или password

**Симптомы:**
- Статус 401 Unauthorized
- Ошибка "Invalid credentials"

**Решение:**
1. Сначала зарегистрируйтесь через `/register`
2. Используйте те же данные для входа

---

### Причина 5: Страница не перенаправляет

**Симптомы:**
- Статус 200 (успешно)
- Но остается на странице входа

**Решение:**
1. Проверьте Console на ошибки JavaScript
2. Пересоберите frontend проект
3. Очистите кэш браузера (Ctrl+Shift+Delete)
