# ⚡ Автоматический запуск BizPulse PRO

## 🎯 Все готово! Просто запустите:

### 1️⃣ Первый раз (настройка):

```
Дважды кликните: setup.bat
```

### 2️⃣ Запуск проекта:

```
Дважды кликните: start_all.bat
```

### 3️⃣ Готово!

Откроется браузер с приложением на http://localhost:3000

---

## 📝 Что происходит автоматически:

- ✅ Проверка всех зависимостей
- ✅ Запуск PostgreSQL и Redis
- ✅ Установка Python зависимостей
- ✅ Установка Node.js зависимостей
- ✅ Запуск Backend (http://localhost:8000)
- ✅ Запуск Frontend (http://localhost:3000)
- ✅ Автоматическое открытие браузера

---

## 🆘 Требования:

- ✅ Docker Desktop (установлен и запущен)
- ✅ Python 3.11+ (установлен)
- ✅ Node.js 18+ (установлен)

Если чего-то нет - скрипты покажут что нужно установить.

---

**Просто запустите start_all.bat! 🚀**
