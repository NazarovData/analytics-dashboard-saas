## 🗄️ Настройка PostgreSQL (опционально):

Если хотите сохранять данные в базе:

1. Создайте базу данных:
```sql
CREATE DATABASE analitix_ai;
```

2. Настройте пароль в `.env`:
```
DATABASE_URL=postgresql://postgres:ваш_пароль@localhost:5432/analitix_ai
```

3. Инициализируйте таблицы:
```cmd
python -m app.core.init_db
```

**Важно:** Если база данных не настроена, приложение всё равно работает, используя память (данные теряются при перезапуске).

1. **Ошибка импорта модуля** - перезапустите сервер
