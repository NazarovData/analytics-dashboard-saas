========================================
  КОМАНДЫ ДЛЯ CMD (ПРОСТОЙ СПОСОБ)
========================================

ВАРИАНТ 1 (САМЫЙ ПРОСТОЙ):
---------------------------
Просто выполните одну команду:

cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS" && ЗАПУСК.bat


ВАРИАНТ 2 (ПОШАГОВО):
---------------------------
Выполняйте команды по одной:

Шаг 1: Перейдите в папку проекта
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS"

Шаг 2: Запустите скрипт
ЗАПУСК.bat


ВАРИАНТ 3 (ВРУЧНУЮ - БЕЗ СКРИПТОВ):
---------------------------
Откройте 2 окна cmd и выполните:

ОКНО 1 - Бэкенд:
----------------
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS"
venv\Scripts\activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

ОКНО 2 - Фронтенд:
------------------
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS\frontend"
npm run dev

ОКНО 3 - Открыть браузеры (через 30 секунд):
---------------------------------------------
timeout /t 30 /nobreak
start msedge http://localhost:3000
start msedge http://localhost:8000/docs


ВАРИАНТ 4 (ОДНА КОМАНДА - ВСЁ ВМЕСТЕ):
---------------------------------------
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS" && start "Backend" cmd /k "venv\Scripts\activate && uvicorn app.main:app --reload --host 0.0.0.0 --port 8000" && timeout /t 15 /nobreak && start "Frontend" cmd /k "cd frontend && npm run dev" && timeout /t 25 /nobreak && start msedge http://localhost:3000 && timeout /t 1 /nobreak && start msedge http://localhost:8000/docs


========================================
  РЕКОМЕНДАЦИЯ:
========================================
Используйте ВАРИАНТ 1 или ВАРИАНТ 2 - они самые простые!
