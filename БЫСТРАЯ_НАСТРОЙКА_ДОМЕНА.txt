========================================
  БЫСТРАЯ НАСТРОЙКА ДОМЕНА
========================================

ДА, ПРОЕКТ РАБОТАЕТ С ДОМЕНОМ!

Текущая конфигурация уже поддерживает домены:
- CORS настроен на "*" (разрешает все домены)
- Серверы слушают на 0.0.0.0 (доступны извне)
- Vite настроен на host: true (доступен извне)


ШАГИ ДЛЯ НАСТРОЙКИ ДОМЕНА:
---------------------------

1. ЗАПУСТИТЕ СКРИПТ НАСТРОЙКИ:
   НАСТРОЙКА_ДОМЕНА.bat
   
   Или вручную:
   ОБНОВИТЬ_CORS_ДЛЯ_ДОМЕНА.bat


2. НАСТРОЙТЕ DNS:
   - Добавьте A-запись: ваш-домен.com → IP сервера
   - Добавьте A-запись: www.ваш-домен.com → IP сервера


3. НАСТРОЙТЕ NGINX (рекомендуется):
   - Используйте файл: nginx/nginx.conf.example
   - Замените "ваш-домен.com" на ваш домен
   - Скопируйте в /etc/nginx/sites-available/
   - Создайте симлинк в /etc/nginx/sites-enabled/


4. УСТАНОВИТЕ SSL:
   sudo certbot --nginx -d ваш-домен.com -d www.ваш-домен.com


5. ОБНОВИТЕ FRONTEND .env:
   Создайте frontend/.env.production:
   VITE_API_URL=https://ваш-домен.com/api/v1


ЧТО УЖЕ РАБОТАЕТ:
-----------------
✅ CORS разрешает все домены (для начала)
✅ Серверы доступны извне (0.0.0.0)
✅ API работает на любом домене
✅ Frontend может работать на любом домене


РЕКОМЕНДАЦИИ ДЛЯ PRODUCTION:
----------------------------
1. Обновите CORS на конкретные домены (безопасность)
2. Используйте HTTPS (SSL сертификат)
3. Настройте Nginx для раздачи статики
4. Используйте переменные окружения для разных сред
