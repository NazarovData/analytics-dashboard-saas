ЕСЛИ НЕ РАБОТАЕТ:
------------------

Вариант 1: Запусти вручную
---------------------------
1. Открой CMD в папке проекта
2. Скопируй и вставь эти команды:

venv\Scripts\activate
pip install reportlab xlsxwriter
python -m uvicorn app.main:app --reload --port 8000

3. Открой НОВОЕ окно CMD
4. Скопируй и вставь:

cd frontend
npm run dev

5. Открой браузер: http://localhost:3000


Вариант 2: Используй готовые файлы
-----------------------------------
Backend:
  ▶️_ЗАПУСТИТЬ_BACKEND.bat

Frontend (в новом окне CMD):
  cd frontend
  npm run dev

6. Скачается красивый отчёт!
