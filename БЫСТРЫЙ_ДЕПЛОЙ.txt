САМЫЙ ПРОСТОЙ СПОСОБ:

1. Загрузите код на GitHub
   git init
   git add .
   git commit -m "Ready for deploy"
   git remote add origin https://github.com/ВАШ-USERNAME/bizpulse-pro.git
   git push -u origin main

2. Зайдите на Railway.app
   https://railway.app
   → Login with GitHub
   → New Project → Deploy from GitHub
   → Выберите ваш репозиторий

3. Добавьте PostgreSQL
   → + New → Database → PostgreSQL

4. Получите URL
   → Settings → Domain
   Скопируйте URL (это ваш Backend)

5. Зайдите на Vercel.com
   https://vercel.com
   → Import Project → GitHub
   → Root Directory: frontend
   → Environment Variable: VITE_API_URL = ваш Railway URL

ГОТОВО! Ваш проект работает бесплатно!
