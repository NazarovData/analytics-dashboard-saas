## 🐛 Возможные ошибки и решения:

### Ошибка: "Библиотека psycopg2 не установлена"
**Решение:**
```cmd
pip install psycopg2-binary
```

### Ошибка: "Подключение не найдено"
**Решение:**
- Убедитесь, что подключение создано
- Проверьте `connection_id`

### Ошибка: "Ошибка подключения к базе данных"
**Решение:**
- Проверьте параметры подключения (host, port, database, username, password)
- Убедитесь, что PostgreSQL запущен
- Проверьте доступность базы данных

### Ошибка: "Ошибка в SQL запросе"
**Решение:**
- Проверьте синтаксис SQL
- Убедитесь, что таблица существует
- Проверьте права доступа

### Ошибка: "Разрешены только SELECT запросы"
**Решение:**
- Используйте только SELECT запросы для безопасности
- Для изменения данных используйте другие методы

## 📊 Примеры правильных SQL запросов:

```sql
-- ✅ Правильно - SELECT запрос
SELECT * FROM users LIMIT 100

-- ✅ Правильно - с группировкой
SELECT category, SUM(amount) as total 
FROM sales 
GROUP BY category

-- ✅ Правильно - с фильтрацией
SELECT date, SUM(revenue) as daily_revenue
FROM transactions
WHERE date >= '2024-01-01'
GROUP BY date
ORDER BY date

-- ❌ Неправильно - DROP, DELETE, UPDATE
DROP TABLE users  -- Запрещено!

UPDATE users SET ...  -- Запрещено!
```
