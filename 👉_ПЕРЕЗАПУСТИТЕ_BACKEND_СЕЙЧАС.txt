🚀 ЧТО ДЕЛАТЬ СЕЙЧАС:

1. Перезапустите backend:
   python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

2. Проверьте:
   http://localhost:8000/api/v1/charts/health

3. Замените API ключ Claude в .env:
   ANTHROPIC_API_KEY=ваш_новый_ключ
