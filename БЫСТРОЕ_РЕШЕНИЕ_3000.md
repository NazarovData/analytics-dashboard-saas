# 🔧 Решение проблемы ERR_CONNECTION_REFUSED на localhost:3000

## ❌ Проблема:
`localhost:3000` не открывается - ошибка `ERR_CONNECTION_REFUSED`

## ✅ Решение:

### ШАГ 1: Убедитесь что frontend запущен

Откройте отдельное окно командной строки и запустите:

```bash
cd frontend
npm install
npm run dev
```

**ИЛИ** дважды кликните на:
```
start_frontend.bat
```

---

### ШАГ 2: Проверьте что сервер запустился

Вы должны увидеть в консоли:
```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
```

**Если этого сообщения нет** - сервер не запущен!

---

### ШАГ 3: Проверьте что порт 3000 свободен

Если порт занят, Vite попробует использовать другой порт (3001, 3002 и т.д.)

Смотрите в консоли на какой порт запустился сервер!

---

### ШАГ 4: Установите зависимости если их нет

Если `node_modules` отсутствует:

```bash
cd frontend
npm install
```

Это может занять 2-5 минут при первом запуске.

---

## 🎯 Быстрый способ (все автоматически):

1. **Закройте все окна командной строки**
2. **Дважды кликните:** `start_all.bat`
3. **Подождите 30-60 секунд**
4. **Откройте:** http://localhost:3000

---

## 🔍 Диагностика:

### Проверка 1: Node.js установлен?
```bash
node --version
```
Должно показать версию (например: v18.17.0)

### Проверка 2: npm установлен?
```bash
npm --version
```
Должно показать версию (например: 9.6.7)

### Проверка 3: Зависимости установлены?
```bash
cd frontend
dir node_modules
```
Должна быть папка `node_modules`

### Проверка 4: Порт занят?
```bash
netstat -ano | findstr :3000
```
Если показывает процесс - порт занят другим приложением

---

## ✅ После исправления:

1. Frontend должен запуститься на http://localhost:3000
2. Backend должен быть на http://localhost:8000
3. Откройте браузер и перейдите на http://localhost:3000

---

**Если проблема осталась - запустите `start_frontend.bat` отдельно и покажите что выводится в консоли!**
