========================================
  ИСПРАВЛЕННЫЕ КОМАНДЫ ДЛЯ CMD
========================================

ПРОБЛЕМА: 'venv\Scripts\activate' не работает
РЕШЕНИЕ: Используйте правильный синтаксис для Windows


ВАРИАНТ 1 (САМЫЙ ПРОСТОЙ):
---------------------------
Просто запустите файл: ЗАПУСК.bat
Он сам создаст и активирует venv если нужно


ВАРИАНТ 2 (АКТИВАЦИЯ VENV):
---------------------------
Правильная команда для активации venv в Windows:

call venv\Scripts\activate.bat

ИЛИ

venv\Scripts\activate.bat

ВАЖНО: Используйте .bat в конце!


ВАРИАНТ 3 (ПОШАГОВЫЙ ЗАПУСК):
---------------------------
Шаг 1: Перейдите в папку проекта
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS"

Шаг 2: Активируйте venv (правильная команда)
call venv\Scripts\activate.bat

Шаг 3: Запустите бэкенд
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000


ВАРИАНТ 4 (ЕСЛИ VENV НЕ СУЩЕСТВУЕТ):
-------------------------------------
Шаг 1: Создайте venv
python -m venv venv

Шаг 2: Активируйте venv
call venv\Scripts\activate.bat

Шаг 3: Установите зависимости
pip install -r requirements.txt

Шаг 4: Запустите бэкенд
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000


ВАРИАНТ 5 (АВТОМАТИЧЕСКАЯ АКТИВАЦИЯ):
--------------------------------------
Запустите файл: АКТИВАЦИЯ_VENV.bat
Он проверит, создаст и активирует venv автоматически
