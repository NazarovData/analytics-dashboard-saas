## 📊 ПОДДЕРЖИВАЕМЫЕ ФОРМАТЫ:

### **Все эти варианты РАБОТАЮТ:**

#### **1. Русский формат:**
```csv
Дата,Товар,Количество,Цена,Клиент
15.01.2024,iPhone,2,80000,ivan@mail.ru
```

#### **2. Английский формат:**
```csv
date,product,qty,price,customer
2024-01-15,iPhone,2,80000,john@mail.com
```

#### **3. Формат из 1С:**
```csv
ДатаДокумента,Номенклатура,СуммаДокумента,Контрагент
15.01.2024,iPhone 15,160000,ООО "Рога и Копыта"
```
💡 Система разделит 160000 / 2 = 80000₽ за штуку

#### **4. Минимальный формат:**
```csv
Название,Сумма
iPhone,100000
MacBook,200000
```
💡 Система добавит: дата=сегодня, количество=1, клиент=CLIENT_1

#### **5. Альтернативные названия:**
```csv
order_date,item_name,units,cost,email
2024-01-15,iPhone,2,80000,test@mail.ru
```
