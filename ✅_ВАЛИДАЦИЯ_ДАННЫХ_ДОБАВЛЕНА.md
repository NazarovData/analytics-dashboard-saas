# ✅ Валидация Данных Добавлена

## Что сделано

Создан новый модуль `app/services/data_validator.py` с функциями для обеспечения 100% точности расчётов.

## 🎯 Функции

### 1. `validate_data_quality(df)` - Проверка качества
Проверяет:
- ✅ Дубликаты строк
- ✅ Пропущенные значения
- ✅ Отрицательные цены/количество
- ✅ Нулевые значения
- ✅ Логику расчётов (total = price × quantity)
- ✅ Аномальные значения (выбросы)
- ✅ Некорректные даты

**Возвращает:** Отчёт с оценкой качества (0-100)

### 2. `auto_fix_data(df)` - Автоисправление
Исправляет:
- ✅ Удаляет дубликаты
- ✅ Заполняет пропущенные значения
- ✅ Пересчитывает total = price × quantity
- ✅ Удаляет отрицательные значения
- ✅ Округляет числа для точности

**Возвращает:** Исправленный DataFrame + отчёт

### 3. `double_check_calculations(analytics, df)` - Двойная проверка
Проверяет:
- ✅ Общую выручку
- ✅ Средний чек
- ✅ Количество заказов
- ✅ Уникальных клиентов

**Возвращает:** Список проверок с результатами

## 📋 Как использовать

### В API endpoint (app/api/v1/files.py):

```python
from app.services.data_validator import (
    validate_data_quality,
    auto_fix_data,
    double_check_calculations
)

# После чтения файла:
df = pd.read_csv(...)

# 1. Проверка качества
quality_report = validate_data_quality(df)

# 2. Автоисправление
df_fixed, fix_report = auto_fix_data(df)

# 3. Расчёт аналитики
analytics = calculate_analytics(df_fixed)

# 4. Двойная проверка
accuracy_checks = double_check_calculations(analytics, df_fixed)

# 5. Возврат результата
return {
    "success": True,
    "analytics": analytics,
    "data_quality": quality_report.to_dict(),
    "auto_fixes": fix_report.to_dict(),
    "accuracy_checks": accuracy_checks
}
```

## 🎨 Как показать в UI

### В DashboardPageNew.tsx:

```typescript
// Показать оценку качества данных
{data.data_quality && (
  <Card className="bg-white/5 border-white/10">
    <CardContent className="p-4">
      <div className="flex items-center justify-between">
        <div>
          <p className="text-sm text-gray-400">Качество данных</p>
          <p className="text-2xl font-bold text-white">
            {data.data_quality.quality_score}/100
          </p>
        </div>
        <Shield className={`h-8 w-8 ${
          data.data_quality.quality_score >= 90 ? 'text-green-400' :
          data.data_quality.quality_score >= 70 ? 'text-yellow-400' :
          'text-red-400'
        }`} />
      </div>
      
      {/* Показать исправления */}
      {data.auto_fixes?.fixes.length > 0 && (
        <div className="mt-3 space-y-1">
          {data.auto_fixes.fixes.map((fix, i) => (
            <p key={i} className="text-xs text-green-400">{fix}</p>
          ))}
        </div>
      )}
    </CardContent>
  </Card>
)}

// Показать результаты проверки точности
{data.accuracy_checks && (
  <Card className="bg-white/5 border-white/10">
    <CardHeader>
      <CardTitle className="flex items-center gap-2">
        <CheckCircle className="h-5 w-5 text-green-400" />
        Проверка точности расчётов
      </CardTitle>
    </CardHeader>
    <CardContent>
      <div className="space-y-2">
        {data.accuracy_checks.map((check, i) => (
          <div key={i} className="flex items-center justify-between p-2 bg-white/5 rounded">
            <span className="text-sm text-gray-300">{check.metric}</span>
            <span className={`text-sm font-medium ${
              check.status === 'ok' ? 'text-green-400' : 'text-red-400'
            }`}>
              {check.message}
            </span>
          </div>
        ))}
      </div>
    </CardContent>
  </Card>
)}
```
