========================================
  БЫСТРАЯ УСТАНОВКА ЗАВИСИМОСТЕЙ
========================================

ПРОБЛЕМА: 'uvicorn' is not recognized
ПРИЧИНА: Зависимости не установлены в venv
РЕШЕНИЕ: Установите зависимости


ВАРИАНТ 1 (САМЫЙ ПРОСТОЙ):
---------------------------
Запустите файл: УСТАНОВКА_ЗАВИСИМОСТЕЙ.bat
(двойной клик)


ВАРИАНТ 2 (ЧЕРЕЗ CMD):
---------------------------
Выполните команды по одной:

Шаг 1: Убедитесь что venv активирован
(должно быть (venv) в начале строки)

Если нет, выполните:
call venv\Scripts\activate.bat

Шаг 2: Установите зависимости
pip install -r requirements.txt

Шаг 3: Дождитесь завершения установки

Шаг 4: Запустите бэкенд
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000


ВАРИАНТ 3 (УСТАНОВКА ТОЛЬКО UVICORN):
--------------------------------------
Если нужно установить только uvicorn:

pip install uvicorn fastapi

Затем запустите:
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000


========================================
  ПРОВЕРКА:
========================================
После установки проверьте:

pip list

Должны быть установлены:
- uvicorn
- fastapi
- и другие зависимости из requirements.txt
