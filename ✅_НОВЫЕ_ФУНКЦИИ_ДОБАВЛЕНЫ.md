## 🎉 ЧТО РЕАЛИЗОВАНО:

### 1️⃣ ABC/XYZ Анализ товаров ✅

**Файлы созданы:**
- `app/services/abc_analysis.py` - сервис анализа
- `app/api/v1/abc_analysis.py` - API endpoints
- `app/main.py` - добавлен роутер

**API Endpoints:**
- `POST /api/v1/abc/abc` - ABC анализ (A/B/C категории)
- `POST /api/v1/abc/xyz` - XYZ анализ (стабильность спроса)
- `POST /api/v1/abc/combined` - Комбинированный анализ (матрица 3x3)

**Что показывает:**
- **Категория A**: 80% выручки - ключевые товары
- **Категория B**: 15% выручки - важные товары
- **Категория C**: 5% выручки - дополнительные товары

- **Категория X**: Стабильный спрос (CV < 10%)
- **Категория Y**: Переменный спрос (CV 10-25%)
- **Категория Z**: Нестабильный спрос (CV > 25%)

**Матрица ABC/XYZ:**
- **AX**: Ключевые товары со стабильным спросом (приоритет 1)
- **AY**: Ключевые товары с переменным спросом (приоритет 2)
- **CZ**: Дополнительные товары с нестабильным спросом (можно убрать)
