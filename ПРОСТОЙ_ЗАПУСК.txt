ВАРИАНТ 3 (Вручную через cmd):
---------------------------
Шаг 1: Откройте cmd и перейдите в папку проекта
cd /d "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS"

Шаг 2: Запустите бэкенд (в новом окне откроется)
start "Backend" cmd /k "venv\Scripts\activate && uvicorn app.main:app --reload --host 0.0.0.0 --port 8000"

Шаг 3: Подождите 10 секунд
timeout /t 10 /nobreak

Шаг 4: Запустите фронтенд (в новом окне откроется)
start "Frontend" cmd /k "cd frontend && npm run dev"

Шаг 5: Подождите 15 секунд
timeout /t 15 /nobreak

Шаг 6: Откройте браузеры
start msedge http://localhost:3000
start msedge http://localhost:8000/docs


========================================
  ЧТО ПРОИСХОДИТ:
========================================
1. Запускается бэкенд на порту 8000
2. Запускается фронтенд на порту 3000
3. Через 25 секунд открываются браузеры Edge
4. Готово!
