========================================
⚡ КОМАНДЫ ДЛЯ ЗАПУСКА В CMD
========================================

ВАРИАНТ 1: АВТОМАТИЧЕСКИЙ ЗАПУСК (САМЫЙ ПРОСТОЙ)
-------------------------------------------------
Просто дважды кликни на файл:
  🚀_ЗАПУСТИТЬ_ВСЁ.bat

Или в CMD:
  🚀_ЗАПУСТИТЬ_ВСЁ.bat


ВАРИАНТ 2: РУЧНОЙ ЗАПУСК (ПО ШАГАМ)
------------------------------------

Шаг 1: Открой CMD в папке проекта
----------------------------------
1. Открой папку проекта в проводнике
2. В адресной строке напиши: cmd
3. Нажми Enter


Шаг 2: Установи reportlab
--------------------------
venv\Scripts\activate
pip install reportlab xlsxwriter


Шаг 3: Запусти Backend
-----------------------
venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Должно появиться:
  INFO:     Uvicorn running on http://0.0.0.0:8000


Шаг 4: Открой НОВОЕ окно CMD и запусти Frontend
------------------------------------------------
1. Открой НОВОЕ окно CMD (не закрывай первое!)
2. Перейди в папку frontend:
   cd frontend

3. Запусти:
   npm run dev

Должно появиться:
  VITE ready in XXX ms
  Local: http://localhost:3000


Шаг 5: Открой браузер
----------------------
Открой в браузере:
  http://localhost:3000

ПРОВЕРКА ЧТО ВСЁ РАБОТАЕТ:
---------------------------

1. Backend работает?
   Открой: http://localhost:8000/health
   Должно быть: {"status":"healthy"}

2. Frontend работает?
   Открой: http://localhost:3000
   Должна открыться страница выбора отрасли

3. API работает?
   Открой: http://localhost:8000/docs
   Должна открыться документация Swagger


ОСТАНОВКА СЕРВЕРОВ:
-------------------
В каждом окне CMD нажми:
  Ctrl + C


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:
-------------------------

Ошибка: "venv не найден"
Решение:
  python -m venv venv
  venv\Scripts\activate
  pip install -r requirements.txt

Ошибка: "reportlab not found"
Решение:
  venv\Scripts\activate
  pip install reportlab xlsxwriter

Ошибка: "npm not found"
Решение:
  Установи Node.js с https://nodejs.org
  Затем:
    cd frontend
    npm install
    npm run dev

Ошибка: "Port 8000 already in use"
Решение:
  Закрой другие процессы на порту 8000
  Или измени порт:
    python -m uvicorn app.main:app --reload --port 8001
