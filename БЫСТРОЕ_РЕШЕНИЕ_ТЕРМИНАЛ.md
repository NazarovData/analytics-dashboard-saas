# ⚡ Быстрое решение проблемы с терминалом

## 🚨 Проблема: Access denied to PowerShell

---

## ✅ БЫСТРОЕ РЕШЕНИЕ (30 секунд)

### Вариант 1: Запустите от имени администратора

1. **Закройте** VS Code/Cursor
2. **Правой кнопкой** на ярлык
3. **"Запуск от имени администратора"**
4. Откройте проект

**Готово!**

---

### Вариант 2: Используйте Command Prompt

1. В VS Code/Cursor нажмите **Ctrl + Shift + `**
2. Нажмите на **стрелку вниз** рядом с "+"
3. Выберите **"Command Prompt"**

**Готово!**

---

### Вариант 3: Используйте внешний терминал

1. Нажмите **Win + R**
2. Введите: `cmd`
3. Перейдите в папку:
   ```cmd
   cd "C:\Users\jobir\OneDrive\Desktop\Дашборд SaaS"
   ```
4. Выполняйте команды там

**Готово!**

---

## 🚀 Для запуска проекта

### В Command Prompt:

```cmd
# Backend
docker-compose up -d

# Frontend (в новом окне)
cd frontend
npm install
npm run dev
```

**Выберите любой вариант - все работают! 🚀**
