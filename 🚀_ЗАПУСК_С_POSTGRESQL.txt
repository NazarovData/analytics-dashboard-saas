========================================
🚀 БЫСТРЫЙ ЗАПУСК С POSTGRESQL
========================================

ШАГ 1: Установить PostgreSQL
-----------------------------
Скачать: https://www.postgresql.org/download/windows/
Или использовать существующий PostgreSQL

ШАГ 2: Настроить PostgreSQL
-----------------------------
Запустить:
  НАСТРОЙКА_POSTGRESQL.bat

Этот скрипт:
- Создаст .env файл
- Установит зависимости
- Запустит миграции
- Создаст все таблицы

ШАГ 3: Запустить Backend
-------------------------
  ▶️_ЗАПУСТИТЬ_BACKEND.bat

ШАГ 4: Запустить Frontend
--------------------------
  cd frontend
  npm run dev

ШАГ 5: Открыть браузер
-----------------------
  http://localhost:3000

========================================
✅ ГОТОВО!

Теперь:
- Загрузите файл
- Посмотрите анализ
- Вся история сохраняется!

========================================
🆘 ПОМОЩЬ:
========================================

Проблема: PostgreSQL не запускается
Решение: Проверить что PostgreSQL установлен и запущен

Проблема: Ошибка миграций
Решение: Проверить DATABASE_URL в .env

Проблема: Frontend не показывает историю
Решение: Проверить что backend запущен на порту 8000
