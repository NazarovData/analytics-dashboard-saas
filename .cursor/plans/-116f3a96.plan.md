# Универсальный дашборд для любого формата CSV

## Проблема

Дашборд показывает 0, потому что данные не загружены. Владельцу бизнеса нужно понятное решение.

## Что будет сделано

### 1. ВАРИАНТ A: Кнопка "Загрузить демо-данные"

- Добавить заметную кнопку "📊 Попробовать с демо-данными"
- При клике автоматически загружает `example_data.csv`
- Показывает уведомление о том, что загружены демо-данные
- Кнопка доступна всегда для быстрого тестирования

### 2. ВАРИАНТ B: Автозагрузка при первом запуске

- При первом открытии дашборда (если данных нет) автоматически загружаются демо-данные
- Показывается баннер: "Загружены демо-данные. Вы можете загрузить свои файлы"
- Сохраняется флаг в localStorage, чтобы не загружать повторно
- Пользователь сразу видит работающий дашборд с данными

### 3. ВАРИАНТ C: Настройка автозагрузки файла

- Добавить кнопку "⚙️ Настройки автозагрузки" в меню
- Модальное окно с выбором файла для постоянной автозагрузки
- Возможность выбрать: демо-данные, последний загруженный файл, или указать путь
- Настройки сохраняются в localStorage
- При каждом открытии дашборда загружается выбранный файл

### 4. Улучшенный индикатор состояния

- Добавить заметный баннер "Загрузите данные для начала работы" когда данных нет
- Сделать зону загрузки файлов более заметной и привлекательной
- Добавить примеры поддерживаемых форматов с визуальными иконками
- Показать пошаговую инструкцию для новых пользователей

### 5. Подсказки для владельца бизнеса

- Добавить всплывающие подсказки (tooltips) к каждой метрике
- Объяснения простым языком: "Что это?", "Как улучшить?"
- Интерпретация данных с рекомендациями
- Показывать, какие колонки были распознаны после загрузки

### 6. Улучшение визуализации "пустого" состояния

- Вместо показа "0 ₽" показывать карточки-плейсхолдеры с призывом к действию
- Добавить анимированные иконки и эффекты
- Показать короткую демо-анимацию загрузки файла
- Добавить примеры CSV файлов для скачивания

### 7. Улучшение парсера CSV

- Добавить поддержку разных разделителей (`,`, `;`, `\t`, `|`)
- Автоопределение кодировки (UTF-8, Windows-1251, CP1252)
- Показывать предпросмотр распознанных колонок перед загрузкой
- Возможность вручную указать какая колонка что означает

## Ключевые файлы

- `frontend/src/pages/DashboardPageNew.tsx` - главный дашборд
- `app/api/v1/files.py` - backend загрузки (уже работает с любым форматом!)
- `example_data.csv` - демо-файл для быстрой загрузки
