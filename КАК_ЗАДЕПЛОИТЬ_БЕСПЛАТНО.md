# 🆓 Как задеплоить BizPulse PRO БЕСПЛАТНО

## 🎯 Самый простой способ - Railway.app

### ⏱️ Время: 10 минут | 💰 Стоимость: БЕСПЛАТНО

---

## 📋 ШАГ 1: Подготовка (2 минуты)

### 1.1. Зарегистрируйтесь на GitHub (если нет аккаунта)
- https://github.com/signup

### 1.2. Создайте новый репозиторий
- Нажмите **"New repository"**
- Название: `bizpulse-pro`
- Выберите **Public** (для бесплатного деплоя)
- Нажмите **"Create repository"**

### 1.3. Загрузите код на GitHub

Откройте командную строку в папке проекта:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ-USERNAME/bizpulse-pro.git
git push -u origin main
```

**Замените `ВАШ-USERNAME` на ваш GitHub username!**

---

## 🚀 ШАГ 2: Деплой на Railway (5 минут)

### 2.1. Зарегистрируйтесь на Railway
- Зайдите на https://railway.app
- Нажмите **"Login"** → выберите **"Login with GitHub"**
- Разрешите доступ к GitHub

### 2.2. Создайте новый проект
- Нажмите **"New Project"**
- Выберите **"Deploy from GitHub repo"**
- Найдите ваш репозиторий `bizpulse-pro`
- Нажмите на него

### 2.3. Railway автоматически определит проект
- Railway увидит `railway.json` и `requirements.txt`
- Начнется автоматическая сборка
- Подождите 2-3 минуты

### 2.4. Добавьте PostgreSQL базу данных
- В проекте нажмите **"+ New"**
- Выберите **"Database"** → **"PostgreSQL"**
- Railway создаст базу автоматически

### 2.5. Настройте переменные окружения
- В настройках сервиса → **"Variables"**
- Railway автоматически добавит `DATABASE_URL`
- Добавьте вручную:
  ```
  SECRET_KEY=ваш-случайный-ключ-минимум-32-символа
  ENVIRONMENT=production
  DEBUG=False
  ```

### 2.6. Получите URL
- В настройках сервиса → **"Settings"**
- Скопируйте **"Domain"** (например: `bizpulse-pro-production.up.railway.app`)
- Это ваш Backend URL!

---

## 🌐 ШАГ 3: Деплой Frontend на Vercel (3 минуты)

### 3.1. Зарегистрируйтесь на Vercel
- Зайдите на https://vercel.com
- Нажмите **"Sign Up"** → выберите **"Continue with GitHub"**

### 3.2. Импортируйте проект
- Нажмите **"Add New..."** → **"Project"**
- Найдите ваш репозиторий `bizpulse-pro`
- Нажмите **"Import"**

### 3.3. Настройте проект
- **Framework Preset**: Vite
- **Root Directory**: `frontend`
- **Build Command**: `npm run build` (автоматически)
- **Output Directory**: `dist` (автоматически)

### 3.4. Добавьте переменную окружения
- В разделе **"Environment Variables"**
- Добавьте:
  ```
  VITE_API_URL=https://ваш-backend.railway.app/api/v1
  ```
  (Замените на ваш Railway URL из шага 2.6)

### 3.5. Деплой
- Нажмите **"Deploy"**
- Подождите 1-2 минуты
- Vercel даст вам URL (например: `bizpulse-pro.vercel.app`)

## 🔧 Если что-то не работает:

### Проблема: Backend не запускается
**Решение:**
1. Проверьте логи в Railway → **"Deployments"** → **"View Logs"**
2. Убедитесь что `DATABASE_URL` установлен
3. Проверьте что `requirements.txt` правильный

### Проблема: Frontend не подключается к Backend
**Решение:**
1. Проверьте `VITE_API_URL` в Vercel
2. Убедитесь что Railway URL правильный
3. Добавьте CORS в Backend (если нужно)

### Проблема: База данных не работает
**Решение:**
1. В Railway → Database → **"Connect"**
2. Скопируйте `DATABASE_URL`
3. Добавьте в Variables сервиса Backend

## 💡 Альтернатива: Все на Railway

Если хотите все в одном месте:

1. В Railway проекте создайте **второй сервис**
2. Выберите ваш GitHub репозиторий
3. Установите **Root Directory**: `frontend`
4. **Build Command**: `cd frontend && npm install && npm run build`
5. **Start Command**: `cd frontend && npx serve -s dist -l $PORT`
