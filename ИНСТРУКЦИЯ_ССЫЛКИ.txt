========================================
  БЫСТРЫЕ ССЫЛКИ ДЛЯ ОТКРЫТИЯ
========================================

СПОСОБ 1 (HTML СТРАНИЦА):
--------------------------
Двойной клик по файлу: ОТКРЫТЬ.html

Или запустите: ОТКРЫТЬ_ССЫЛКИ.bat

Откроется красивая страница с кнопками:
- 📊 Открыть Фронтенд
- 🔧 Открыть API Документацию

Просто нажмите на кнопку и откроется нужная страница!


СПОСОБ 2 (ПРЯМЫЕ ССЫЛКИ):
-------------------------
Скопируйте и вставьте в браузер:

Фронтенд:
http://localhost:3000

API Документация:
http://localhost:8000/docs


СПОСОБ 3 (ЯРЛЫКИ):
------------------
Создайте ярлыки на рабочем столе:

1. Правой кнопкой на рабочем столе → Создать → Ярлык
2. Введите: http://localhost:3000
3. Назовите: "BizPulse Frontend"
4. Повторите для: http://localhost:8000/docs
5. Назовите: "BizPulse API"


ВАЖНО:
------
Перед открытием убедитесь что серверы запущены:
- Запустите ЗАПУСК_ПРОСТОЙ.bat
- Дождитесь запуска серверов
- Затем откройте ОТКРЫТЬ.html или используйте ссылки
